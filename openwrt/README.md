# OpenWRT

Router: netis NX31 (`mediatek/filogic`, profile `netis_nx31`), OpenWrt 25.12.5 (`apk`), xray-core 26.3.27.

## Upgrade
Custom files outside `/etc/config` are kept via `/etc/sysupgrade.conf`:
```
/etc/xray/
/etc/firewall.xray
/etc/hotplug.d/iface/99-xray-tproxy
/etc/hotplug.d/iface/30-vpnroute
/etc/hotplug.d/net/30-vpnroute
/usr/share/v2ray/
/root/
```
`owut upgrade` rebuilds the image from user-installed packages only, so packages that came with the old
image are dropped. After the upgrade reinstall them and start xray:
```
apk update && apk add xray-core kmod-nft-tproxy curl ip-full bind-dig coreutils-base64 kmod-tun
/etc/init.d/xray enable && /etc/init.d/xray restart && fw4 reload
```
Keep `/etc/config/xray` (`datadir /usr/share/v2ray`, no `confdir`) and ignore `xray.apk-new`.

## Geo update
`geo-update.sh` (copy of `/etc/xray/geo-update.sh`, cron `17 4 * * *`) downloads geo dat files and the `geoip:` lists
from the `latest` release, checks them against `SHA256SUMS`, and rebuilds the nft set `inet xray direct_dst`.
```
scp -O openwrt/geo-update.sh root@192.168.1.1:/etc/xray/
ssh root@192.168.1.1 /etc/xray/geo-update.sh
```

## Strip config 
```
jq '.outbounds |= map(del(.settings, .streamSettings))' /etc/xray/config.json
```

## Subscription update
`sub-update.sh` (copy of `/etc/xray/sub-update.sh`, cron `0 * * * *`) rebuilds the `proxy-NN` outbounds of
`/etc/xray/config.json` from `/etc/xray/subscriptions.txt` (one https URL per line, `#` comments). Each URL must
return an xray JSON config; every non-freedom/blackhole/dns outbound in it becomes `proxy-NN` in file order.
- only `protocol`, `settings`, `streamSettings` are replaced; flat vless settings are converted to `vnext` (xray 25.1)
- a new reality `shortId`/`spiderX` alone is ignored (providers randomize them per request)
- a failed subscription keeps its old outbounds (`subscriptions.state` maps URL -> tags), orphan `proxy-*` are removed
- `xray -test` before applying, restart only on change, `config.json.prev` restored if xray does not start
```
scp -O openwrt/sub-update.sh root@192.168.1.1:/etc/xray/
ssh root@192.168.1.1 /etc/xray/sub-update.sh --dry-run   # show changes, touch nothing
ssh root@192.168.1.1 logread -e sub-update
```

## PAC for Proxy Switcher
`proxy.pac` is built by `geo.yaml` (`geo2pac.py`) from the same lists as the geo files:
geosite/geoip matches go `DIRECT`, everything else goes to `SOCKS5 127.0.0.1:9050`.
Change the proxy by editing `var PROXY` at the top of the file (or `-p` in the workflow).
```
python3 openwrt/geo2pac.py <dir with geosite-*.txt and geoip *.txt> -p "SOCKS5 127.0.0.1:9050" -o proxy.pac
```
