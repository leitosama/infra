
## PAC for Proxy Switcher
`proxy.pac` is built by `geo.yaml` (`geo2pac.py`) from the same lists as the geo files:
geosite/geoip matches go `DIRECT`, everything else goes to `SOCKS5 127.0.0.1:9050`.
Change the proxy by editing `var PROXY` at the top of the file (or `-p` in the workflow).
```
python3 openwrt/geo2pac.py <dir with geosite-*.txt and geoip *.txt> -p "SOCKS5 127.0.0.1:9050" -o proxy.pac
```

### Test a PAC in real Chromium
`openwrt/pac-chrome-test/` loads a PAC the same way Proxy Switcher's "Inline" mode does
(`chrome.proxy.settings.set` with `pacScript: {mandatory: true, data}`) and fails on `ERR_PAC_SCRIPT_FAILED`.
Needs `playwright` and Chromium.
```
node openwrt/pac-chrome-test/run.js proxy.pac            # as is
node openwrt/pac-chrome-test/run.js proxy.pac --oneline  # newlines collapsed
```
If Proxy Switcher still reports `ERR_PAC_SCRIPT_FAILED`, re-convert the PAC: the old script stays stored in the Inline editor. The first line of a good one is `/* Generated by ...`.
